# API 仕様（実装済みのもの）

本書は実装済みの API だけを載せます。未実装の機能は書きません。

- 認証：なし。管理 API は Cookie `ab_session`（有効期限 86400 秒）の値を所有者キーとして、そのセッションが作った実験だけを参照・操作できます。
- 計測 API（`/t/...`）は Cookie を使わず、実験ごとの公開キー（32 文字）で識別します。CORS は全オリジンを許可します。
- 日次リセット（JST 03:00）で全データが消えます。

## 管理 API

| タイトル | メソッド | エンドポイント | 内容 |
|---|---|---|---|
| 実験一覧 | GET | `/api/experiments` | 自分のセッションの実験を一覧で返す |
| 実験の作成 | POST | `/api/experiments` | 実験を作成する（本文：`name`・`goalName`・`minSample`・`variants`（`key`・`label`・`weight`・`payload`）。バリアント 2〜4 件） |
| 実験の取得 | GET | `/api/experiments/:id` | 実験 1 件を返す |
| 実験の更新 | PUT | `/api/experiments/:id` | 実験の内容（名前・バリアント・配分率など）を更新する |
| 状態の変更 | POST | `/api/experiments/:id/status` | 実験を開始・一時停止・停止する |
| 擬似トラフィック | POST | `/api/experiments/:id/simulate` | 展示用に擬似訪問者を生成する |
| 結果の取得 | GET | `/api/experiments/:id/results` | バリアント別の露出数・転換数・転換率・リフト・統計判定を返す |

## 計測 API

| タイトル | メソッド | エンドポイント | 内容 |
|---|---|---|---|
| 割当 | GET | `/t/:publicKey/assign` | 訪問者（`visitor_id` クエリ）にバリアントを割り当てる。保存済みの割当を優先する |
| 転換の記録 | POST | `/t/:publicKey/convert` | 割当済みの訪問者の転換（ゴール達成）を記録する（本文：`visitorId`・`goalName`）。（割当, ゴール）単位で一意 |

## 埋め込み

| タイトル | メソッド | エンドポイント | 内容 |
|---|---|---|---|
| スニペット | GET | `/snippet.js` | 任意のページに貼る JS。割当結果に従って指定要素の文言・色を差し替える |

## 上限

- 1 実験あたりの受付イベント数：10,000 件（上限到達後は対照に固定し、記録を停止）
- 1 セッションあたりの実験数：5 件
