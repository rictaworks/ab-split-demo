# データフロー図（DFD・実装済み）

本書は、データがどこから入り、どこで処理され、どこに保存されるかを示します。図は Mermaid で書いています。

## レベル 0（コンテキスト図）

```mermaid
flowchart LR
    Op["実験運営者<br/>（ブラウザ）"]
    Vis["訪問者<br/>（埋め込み先のページ）"]
    Sys(("A/B テスト展示デモ<br/>Cloudflare Workers"))
    DB[("D1（SQLite）")]
    GA["GA4"]

    Op -- "実験の作成・更新・状態変更・模擬・結果の閲覧" --> Sys
    Sys -- "実験の一覧・詳細・結果" --> Op
    Vis -- "割当の要求・転換の通知（公開キー）" --> Sys
    Sys -- "バリアントの指定・スニペット" --> Vis
    Sys -- "読み書き" --> DB
    Vis -. "ページ表示の計測" .-> GA
```

## レベル 1（処理の分解）

```mermaid
flowchart TB
    subgraph Admin["管理（Cookie ab_session で所有者を識別）"]
        P1["1. 実験管理"]
        P2["2. 模擬トラフィック"]
        P3["3. 結果集計"]
    end
    subgraph Track["計測（公開キーで実験を識別）"]
        P4["4. 割当"]
        P5["5. 転換記録"]
    end
    Daily["6. 日次リセット<br/>（JST 03:00）"]

    D1[("experiments")]
    D2[("variants")]
    D3[("assignments")]
    D4[("conversions")]

    U["運営者"] --> P1
    U --> P2
    U --> P3
    V["訪問者のブラウザ"] --> P4
    V --> P5

    P1 -- "作成・更新・状態" --> D1
    P1 -- "バリアント" --> D2
    P2 -- "擬似の割当・転換" --> D3
    P2 -- "擬似の転換" --> D4
    P3 -- "読み取り" --> D3
    P3 -- "読み取り" --> D4
    P4 -- "実験の読み取り・割当の保存" --> D3
    P4 -- "上限到達で capped" --> D1
    P5 -- "割当の読み取り・転換の保存" --> D4
    P5 -- "上限到達で capped" --> D1
    Daily -- "全行を削除" --> D1
    Daily -- "全行を削除" --> D2
    Daily -- "全行を削除" --> D3
    Daily -- "全行を削除" --> D4
```

## 要点

- 管理の処理（1〜3）は、Cookie の `owner_session_id` で絞り込みます。他人の実験は見えません。
- 計測の処理（4・5）は Cookie を使わず、公開キーで実験を引きます。
- 個人情報は流れません。訪問者 ID は、ブラウザ内で生成した乱数です。
