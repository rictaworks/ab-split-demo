# 画面仕様（実装済みのもの）

本書は実装済みの画面だけを載せます。

## ページ一覧

| ページ名 | URL | 内容 |
|---|---|---|
| 実験一覧 | `/` | 自分のセッションの実験を一覧で表示し、新しい実験を作成する |
| 実験の詳細・結果 | `/experiments/:id` | 実験の編集、状態の変更、埋め込みスニペット、擬似トラフィック、結果を表示する |
| 法的表記 | `/legal` | 運営者・連絡先・個人情報と Cookie・データ削除の説明 |
| 概要（LP） | `/lp` | デモの概要、主な機能、上限、個人情報の扱い。マニュアルへのリンクを置く |
| マニュアル | `/manual` | 実験の作成から結果の確認までの手順（12 段階）と注意 |
| 404 | 上記以外 | 見つからないことを示すページを表示する |

スニペット（`/snippet.js`）は画面ではなく、埋め込み用の JS です（[api.md](api.md) を参照）。

## 全画面の共通要素

すべての画面で、次を同じレイアウトで表示します（`src/views/layout.ts`）。

| 要素 | 実装 |
|---|---|
| アンバーバナー | 最上部に「デモ版です。データは毎日 JST 03:00 にすべて削除されます。」 |
| 「← デモ一覧へ」 | ナビ右端。リンク先は `DEMO_LIST_URL`（本番は `https://rictaworks.jp/#demos`） |
| 「ご相談はこちら」 | 右下固定。リンク先は `mailto:info@rictaworks.jp` |
| フッターのリンク | 「概要」（`/lp`）・「マニュアル」（`/manual`）・「法的表記」（`/legal`） |
| GA4 タグ | 全画面に `G-C04W1XKS16`（Secret `GA4_MEASUREMENT_ID`） |
| テーマ | ライト固定。`prefers-color-scheme` の分岐は無い |

### 仕様との差異（未決）

- 「ご相談はこちら」のリンク先：`requirements.md` §8 と共通項目は `https://rictaworks.jp/`。実装は `mailto:`。どちらに統一するかは未決。
- 右下ボタンの位置：共通項目は `1.5rem`（24px）。実装は `16px`。
- `/legal`：共通項目は「利用規約・免責事項・連絡先」の節とフッターのリンクを求める。実装は「法的表記」1 節だけ。
